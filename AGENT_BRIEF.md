# Madraspuram — Agent Brief (One-Location Demo)

Capability demo: a TGYH-grammar Chennai slapformer slice. Inspiration from the longer street brief; **scope is Approach A** (tea-hub episode only).

## Locked decisions

- **Engine:** Godot 4.3+ GDScript only; web + desktop; `demo` feature tag on web.
- **Art/SFX:** Code-authored only (SVG + procedural WAV). No AI images, no downloads.
- **Protagonist:** UNIT-07 boxy robot; walk / jump / push; beeps only.
- **Location:** George Street hub — bus stop → டீ கடை → auto stand + milk.
- **Language:** Tamil speech bubbles; slightly-wrong English robot subtitles.
- **UI:** TGYH-pure (no inventory / quest log / heat meter). Heat is diegetic.
- **Tone:** Affectionate Chennai parody. No real brands, politicians, or film stars.

## Quest

1. Bus ejects robot. Destination: government office (teased, not reached).
2. Tea master blocks lane until milk arrives.
3. Auto blocks milk; fare negotiation via pushes; reverses into coconut stall.
4. Grab milk packet past auto.
5. Deliver milk → long pour → tea cools robot → end card.

Flags: `auto_moved`, `has_milk`, `tea_done` (+ optional `dog_following`).
